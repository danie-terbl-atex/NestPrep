# Lessons

- **A build for Daniel's own iPhone carries the demo logins and installs in place.** `flutter build ios --release --dart-define-from-file=demo_logins.json`, then `xcrun devicectl device install app --device <id> build/ios/iphoneos/Runner.app`. A plain release build drops the one-tap logins, and `flutter install` uninstalls first and signs him out (2026-10-24, "Add back the debug logins").
- **Godfather's `write_doc` with an `id` always writes; there is no dry run.** A bogus `node` does not stop it. On 2026-11-01 a "dry run" call replaced the add-to-checkers overview with `PLACEHOLDER` (rev 9), restored as rev 10. Only call it with the complete body you mean to save.
- **The Android emulator can't be launched from this agent's shell.** qemu fails `mprotect: Permission denied` and adb shows it `offline` for ever, sandboxed or not. Don't spend time on it: ask Daniel to start the AVD, or use a real device (2026-11-01).
- **Write a Godfather ADR as `proposed`, read back the display id it was given, then accept it.** Accepted ADRs refuse every edit, even a wrong number in the title or a wikilink to the wrong node. On 2026-11-02 the accounts ADR saved as ADR-0010 under a title saying ADR-0007 (search hid ADR-0007..0009), and live-location ADR-0003 links household and accounts ADRs by bare number, which resolves on its own node. Search per node can miss ADRs — list the node's ADRs before choosing a number, and always link across nodes as `[[<node path>:ADR-NNNN|...]]`.
- **A native engine is not done until it has run once against a real backend and its writes have been seen landing.** The iOS location engine passed 61 XCTests with fakes and never touched Firestore. On a phone, its first write after every relaunch was lost for good, and the live pin froze while the trail kept arriving (2026-11-04, "collapses on iPhone once app is closed"). Drive it with a throwaway integration test on the Simulator against the emulator suite, step the location with `xcrun simctl location <sim> set`, and read the emulator documents; `simctl location start` exits at once and moves nothing.
- **Check for a running emulator suite before starting one, and never include Storage in a second suite.** Every Storage emulator shares `$TMPDIR/firebase/storage/blobs` and deletes it on exit, whatever its ports. On 2026-11-05 a separate-port `emulators:exec --only firestore,auth,functions,storage` beside Daniel's LAN suite deleted its blobs at exit. `curl -s http://127.0.0.1:4400/emulators` first; if one answers, use `--only firestore,auth,functions` (Godfather lesson on the shared blobs folder).
- **Godfather's `write_doc` saves a new ADR as `accepted` unless `status: proposed` is passed** — and an accepted ADR refuses every later edit. Always pass the status on a new ADR (2026-11-05, Woolworths ADRs).
- **Pass the emulator lessons into every subagent brief that may run a suite.** On 2026-11-05 the Woolworths Functions agent, told only "use isolated ports", started a second suite with Storage and deleted Daniel's running suite's blobs folder again. Say it explicitly: `--only firestore,auth,functions`, never Storage.
- **Format and fix only the files you changed; this working tree holds other sessions' work in flight.** `dart format lib test tool` or a bare `dart fix --apply` re-wraps their unformatted files too, and staging by path afterwards cannot tell whose whitespace is whose. Pass the exact paths (`git status --porcelain` before and after). On 2026-11-05 a whole-tree format ran beside the Woolworths and chore-pictures sessions.
- **A deploy from a clean copy rolls back whatever other sessions already released.** On 2026-11-05 I deployed rules and every Function from master + Woolworths only, to keep in-flight work out. But chore pictures had already released its rules at 12:41, and my 12:42 rules deploy refused task pictures in production until that session restored them. Rules are one ruleset: always build them from the main tree's partials. For Functions, deploy only your own (`--only functions:a,functions:b`), never all of them, unless the whole tree is what is meant to be live.
