# The grocery list

**Who it's for:** anyone who shops. **Devices on screen:** two phones (parent and helper) showing the same list update live.

## Steps
1. **Lists → Groceries.** Type in "Add an item" (and "How much?" if you like) → **Add**.
2. "Often bought" chips add an item back with one tap.
3. Tick an item to move it from "To buy" to "Bought". **Undo** puts it back.
4. **Filled from your plans:** "This week's plans need N things" → **Review**.
   - Changes are grouped as To add, Amounts changed, No longer planned, and Bought recently.
   - **Update the list · N changes** applies them.
5. Turn on **Keep the list in step** and the list updates itself. It never touches anything somebody typed or ticked.
6. Show the helper adding "dishwashing liquid" on her phone, and it appearing on the parent's.
7. Items can also be added from the kitchen frame: [using-the-frame-by-touch](../../10-nestprep-home-frame/using-the-frame-by-touch/).
