# Compare shops

**Who it's for:** a parent watching the budget. **Devices on screen:** the parent's phone.

**Before filming:** two or more shops switched on, and unbought items on the list.

## Steps
1. **Lists → Groceries → Compare prices across shops** ("Checking prices… 3 of 8").
2. It says "{Shop} is cheapest · You save R…". "What each shop costs" shows each total, and what each shop doesn't have.
3. **Use {shop} for this list** → **Use {shop}**, or **Keep my picks**.
4. Then fill that shop's cart: [fill-your-shop-cart](../fill-your-shop-cart/).
