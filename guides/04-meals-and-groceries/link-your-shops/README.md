# Link your shops

**Who it's for:** a parent who orders online. **Devices on screen:** the parent's phone, with an SMS arriving for Checkers.

## Steps
1. Account button → **Account and privacy → Shopping → Your shops**.
2. Set **Shop first at** (Checkers, Pick n Pay or Woolworths). This is kept on this phone.
3. **Checkers Sixty60:** **Link Checkers** → Mobile number → **Send code** → enter the SMS code → **Link account**. It shows "Checkers is linked · until {time}"; the link lasts an hour, then needs a new code.
4. **Pick n Pay:** **Link Pick n Pay** → **Sign in to Pick n Pay**. This is Pick n Pay's own sign-in page, so nestprep never sees the password.
5. **Woolworths Dash:** **Link Woolworths** → email and password → a code, if asked → **Link account**.
6. Each linked shop shows a masked number or email, with **Manage**.

## Say this on screen
- nestprep only fills **your own** cart. You always check out and pay in the shop's app.
