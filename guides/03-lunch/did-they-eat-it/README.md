# Did they eat it?

**Who it's for:** a parent after school. **Devices on screen:** the parent's phone.

**Before filming:** Premium.

## Steps
1. **Food → Lunch** → a past day's box → "Did it come home eaten?"
2. Tap **Ate it** or **Left it**, or **Item by item** ("What came home eaten?") → **Save**. **Change** corrects an answer.
3. The next time you pick food, the picker shows "Likes it", "Eaten N times" and "Left N times".
4. Twig's next plan leans towards what gets eaten.
