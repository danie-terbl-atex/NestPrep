# Using the frame by touch

**Who it's for:** the family in the kitchen, kids included. **Devices on screen:** the frame, with a phone showing each change arrive.

## Steps
1. **Chores:** each child has a column. Tap a chore → the celebration plays ("Well done, X! +2 stars"), or "A grown-up will check it".
2. **To do:** Family to-dos and the helper's list → tap an item → **Mark as done** → **Who did it?** → "Done. One less thing." **Not done yet** undoes it.
3. **Add an event:** Calendar → **Add event**:
   - "What's happening?"
   - When
   - Who's it for?
   - Once or Every week
   - **Who's adding it?**

   → **Add to the calendar** → "Added. One less thing to remember."
4. **Add groceries:** Groceries → **Add groceries** → "What do you need?":
   - results **From Checkers / Pick n Pay / Woolworths**, or **Just add "…"**
   - **Who's adding?**

   → "Added to the list."
5. Show the new item and event on the parent's phone a moment later.

## Setup (on the phone)
- Frame settings → **Add groceries from the frame** → choose the **Shop** and **Prices near**.
- The frame only finds products. "The frame never fills a cart."
