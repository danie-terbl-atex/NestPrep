# Set up and link the frame

**Who it's for:** a parent unboxing the frame. **Devices on screen:** the frame and the parent's phone, side by side.

**Before filming:** the `photoFrames` switch on. Only a parent can link a frame.

## Steps: the frame
1. Plug it in. nestprep Home starts by itself.
2. **Connect to Wi-Fi:** tap your network → type the password → **Connect** → "Connected to X". It needs 2.4 GHz.
3. **Put the family on the wall** shows a QR code and a six-letter code, with "Waiting for your phone…". The code renews every 10 minutes.

## Steps: the phone
1. **More → Around the house → Photo frames → Link a frame**.
2. Scan the QR, or **Type the code instead** → **Next**.
3. **Name:** "Kitchen frame".
4. **What it shows** (choose any):
   - Calendar, and **Add events from the frame**
   - To-dos
   - Meals
   - Lunch boxes (off by default)
   - A helper's day
   - Open recipes and pages shared from phones
5. **Link frame** → "Linked — it'll fill in a few seconds" → **Done**.
6. Cut to the frame filling with the family's day.
