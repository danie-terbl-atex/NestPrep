# Set up the nanny hub

**Who it's for:** a parent before the nanny's first shift. **Devices on screen:** the parent's phone.

**Before filming:** the child added as a Child, with allergies and medication in Family profiles.

## Steps
1. **More → Around the house → Nanny hub**.
2. **Child cards:** under "Children", tap the child, then:
   - **Edit routine** → **Add a step**
   - **Edit comfort items** and **Edit how to settle them**
   - **Add a photo**

   Allergies and medication come from Family profiles.
3. **Emergency numbers:**
   - **Edit address and medical aid**
   - "People to call" → **Add a contact** (Parent, Backup adult, Doctor, Hospital, Other)
4. **House guide** → **Add a place** → **Take a photo**, "What is here", "Where exactly".
5. **House rules** → **Add a rule**.
6. **Shift checklists:** Edit arrival, after school, dinner, bath and bedtime, or before leaving → **Add** → **Save**.
7. Show the nanny's view of the same hub: [the-carers-shift](../the-carers-shift/).
