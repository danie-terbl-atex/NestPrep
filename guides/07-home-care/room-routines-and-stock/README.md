# Room routines and stock

**Who it's for:** a parent. **Devices on screen:** the parent's phone, then the grocery list.

**Before filming:** the `homeCareRoutines` and `homeCareStock` switches on.

## Steps
1. Home care → **Room routines** → **New routine**: Daily, Weekly or Deep clean → **Add a thing to do**.
2. The helper sees today's rooms on her Home care screen, and on the frame if it's set up ([a-helpers-day-on-the-frame](../../10-nestprep-home-frame/a-helpers-day-on-the-frame/)).
3. **Stock:** set each product to Full, Half, Low or Out.
4. Low or Out moves it to "Running low", tagged "On the grocery list".
5. On Groceries, it shows under "From this week's plans", or is added by itself when **Keep the list in step** is on.
