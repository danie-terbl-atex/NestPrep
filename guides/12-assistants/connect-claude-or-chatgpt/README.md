# Connect Claude or ChatGPT

**Who it's for:** Admins and Parents. **Devices on screen:** the parent's phone, and Claude (or ChatGPT) on a laptop.

**Before filming:** the `assistants` switch on.

## Steps
1. **More → Elsewhere → Connected assistants** → **Copy address**.
2. In Claude: Settings → Connectors → **Add custom connector** → paste the address. ChatGPT takes the same address.
3. A browser opens: **Sign in to nestprep** → choose the household → tick what it may do (calendar, grocery list) → **Allow**.
4. Ask it: "Add swimming on Thursday at 4 for Ava, and put milk on the list."
5. In the app, the event and item appear, marked "via Claude".
6. **Connected assistants** shows recent activity, the **Let assistants work in this household** switch, and **Disconnect**.
