# The family calendar

**Who it's for:** anyone in the family. **Devices on screen:** a parent's phone, then the frame showing the same week.

## Steps
1. **Calendar** → add an event: "What is happening?", Starts, All day, Repeats, and For (who) → **Save**.
2. A repeating event also offers **Skip this one**.
3. **Quick add:** type "Soccer Tuesdays at 5" → check the preview → **Add**.
4. Each member's colour is set under Household → person → **Colour**.
5. **Birthdays:** set under Household → person → **Birthday**. They appear every year ("{name} turns N").
6. **This week, shared** (More, parents only) shows who does what this week. **Share** sends it as a picture.
