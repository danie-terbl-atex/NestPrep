# Connect calendars and snap a school letter

**Who it's for:** a parent. **Devices on screen:** the parent's phone, and a printed school letter.

## Steps
1. **Calendar** → two-arrows icon → **Bring a calendar in** → Google Calendar or Outlook → **Connect**. It's read-only: "Nothing is ever changed in your own calendar."
2. **Apple or a calendar link:** paste the webcal link → **Add calendar**.
3. **The family week, in your own calendar** → **Get the link** → **Subscribe on this phone**.
4. **Snap a school letter:** scan icon → photo or PDF of the letter → "We found N events" → **Add N events**.

## Not live yet / check first
