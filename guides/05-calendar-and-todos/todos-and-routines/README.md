# To-dos and routines

**Who it's for:** a parent. **Devices on screen:** the parent's phone.

## Steps
1. **Lists → To do** (Mine / Everyone / Chores).
2. **Add a task** → "What needs doing?", a picture, Due, Repeats (every day, week or month, with On and Until), For (members or Anyone) → **Save**.
3. **Routines** (admins): Everyone → **Add a routine** (name, start, repeat, "Usually for", colour). New tasks can join it under "Part of a routine".
4. Tick a task → "Done", with **Undo**.
5. To-dos also show on the frame, where anyone can tick them: [using-the-frame-by-touch](../../10-nestprep-home-frame/using-the-frame-by-touch/).
