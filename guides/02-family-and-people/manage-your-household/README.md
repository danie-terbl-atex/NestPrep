# Manage your household

**Who it's for:** an Admin. **Devices on screen:** the admin's phone.

## Steps
1. **Switch household:** Account button → **Switch household** → tap one. This only shows when you belong to more than one.
2. **Remove someone:** Household → **Remove** on their row → **Remove**.
3. **Leave:** **Leave household** → confirm. The only admin must make someone else an admin first.
4. **Close the household** (when you're the only adult left):
   1. **Close household**, then read "What is deleted" and "What stays".
   2. Optional: **Download my data first**.
   3. Type `CLOSE` → **Close household for good**.
5. **Time zone:** Manage people → **Household settings** → Time zone.
