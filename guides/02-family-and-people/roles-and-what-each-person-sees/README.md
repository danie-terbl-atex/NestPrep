# Roles, and what each person sees

**Who it's for:** a parent who wants to know what everyone else's app looks like. **Devices on screen:** four phones side by side (parent, nanny, helper, child), each on the same tab.

## Steps
1. Explain the five roles: Admin, Parent, Child, Helper, and Nanny or carer.
2. Household → a person → **What they can see**.
3. For each area, choose **Hidden / Only theirs / Can see / Can change**. **Suggested for the role** and **Nothing** are quick presets.
4. **Save**. The person sees their own summary under "What you can use here".
5. Show how a tab disappears when every area in it is Hidden. For example, a helper's Food tab opens straight on Meals.

## Default access by role

| Area | Admin / Parent | Child | Helper | Nanny or carer |
|---|---|---|---|---|
| Calendar | all | can see | can see | can see |
| Groceries | all | can see | **can change** | can see |
| To-dos and chores | all | only theirs | only theirs | only theirs |
| Meal plan | all | can see | can see | can see |
| Lunch boxes | all | only theirs | hidden | can see |
| Family profiles | all | only theirs | hidden | can see |
| Medication | all | hidden | hidden | can see |
| Home care | all | hidden | **only theirs** | hidden |
| Nanny hub | all | hidden | hidden | **can change** |
| Documents | all | hidden | hidden | hidden |
| Where we are | all | can see | hidden | hidden |

Only Admins manage people, invites and access. Plan and billing, stars and two homes are for Admins and Parents.
