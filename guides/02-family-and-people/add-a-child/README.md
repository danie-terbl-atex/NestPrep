# Add a child, and their own sign-in

**Who it's for:** a parent (Admin). **Devices on screen:** the parent's phone and the child's tablet or phone, side by side.

**Before filming:** a second child needs Premium, because the free plan covers one child.

## Steps: add the child
1. **More → People → Manage people → Add a person**.
2. Fill in Name and Colour, set Role = **Child**, and add a Birthday (a date, day and month only, or not set).
3. Tick the parent's consent ("I am this child's parent or legal guardian…") → **Save**.
4. **More → Family profiles** → tap the child, and check **This is a child** so lunches are planned for them.
5. Fill in the profile:
   - **Allergies**, with how serious each is
   - **Food**: Likes, Won't eat, Diet (Nut-free, Halal…)
   - **School**: school, Grade, Nut-free school
   - **Medication**: medicine, dose, when
   - **Sizes**: clothes, shoes

## Steps: the child signs in on their own device (no email)
1. Parent: Household → **Kids' sign-in** → **Add a device** → name the device → **Make a code**. A 6-letter code counts down: "Waiting for the device…"
2. Child's device: open nestprep → **I have a code** → type the code → **Continue** → "Hello there!" signs them in.
3. The parent sees "[Name] is signed in!" → **Done**.

## What the child sees
A single screen, **My day**, with no tab bar:
- "Hi, [name]!" and their stars
- **My jobs today** (tap when done)
- today's lunch box and **Today's food**
- treats to save for
- **Sign this device out**

## Also
- The parent can **Sign out** one device or **Sign out everywhere** from Kids' sign-in. The limit is 5 devices per child.
- An older child with their own phone can be invited instead ("A child with a phone"). They get a full account limited by the Child role; see [roles-and-what-each-person-sees](../roles-and-what-each-person-sees/).
