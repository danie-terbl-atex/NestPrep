How it works

  • Redeem your code here with your email.
  • Sign in to the NestPrep app with that same email.
  • The app shows the Premium waiting for you. Choose the household to add it to.

A code has a set number of places, and a place is yours once you add the Premium to your household. Each household can use one code a year.
